# v0.16.2 - 2026-11-26

> 🖼️ **图片入站即缓存**：QQ 图片链接几分钟就过期，以前模型开窗后再去 `download_qq_file` 永远拿到 "download url has expired"，于是反复抱怨「图拉不下来」。现在消息一到就把图片下载到本地，快照里直接给本地路径，模型用 `read_image` 看。

## Added

- 顶层 `media` 配置（`models/config/media_config.py`）：
  - `enable`（默认 `true`）：入站媒体缓存开关；
  - `path`（默认 `null`，用插件 `data/media`）：缓存目录；
  - `max_megabytes`（默认 `20`）：单个文件大小上限；
  - `max_files`（默认 `500`）：缓存目录最多保留多少个文件，超出按修改时间淘汰；
  - `timeout_seconds`（默认 `10`）：单个下载超时。
- `core/media_cache.py`：`MediaCache`（后台下载 + 同一 URL 去重 + 大小上限 + 目录淘汰）与 `url → 本地路径` 登记表。
- 主入口 `backlog_anything` 入队后立刻 `asyncio.create_task` 下载图片；`render_segment` 命中缓存时渲染成 `[图片 名字 已缓存:/path]`，不再给会过期的 URL。

## Changed

- 群聊语境提示追加两条：图片若是「已缓存」路径就直接 `read_image` 看；工具失败一句话带过，别反复抱怨或解释内部报错。
- `send_meme_to_qq` 对 hash 做归一化兜底：去空白、转小写、只留 hex、去掉超长前缀、左侧补 0 到 32 位；原 hash 匹配不到时用归一化后的再试一次，修掉「模型少打一个前导 0 → 找不到表情包」。
- `main.submit_now()`（状态机关闭时的退化路径）补传 `config` 给 `social.on_submit()`，修掉签名变更后隐藏的 `TypeError`。

## Config

```yaml
media:
  enable: true
  path: null
  max_megabytes: 20
  max_files: 500
  timeout_seconds: 10.0
```

`enable: false` 退回 0.16.1 行为（快照里给 URL，模型自己下载，链接大概率已过期）。
