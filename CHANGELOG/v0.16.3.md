# v0.16.3 - 2026-11-26

> 🛑 **一轮发送预算**：主包的 agent 是一轮多步的工具循环，模型可以在一轮里反复调 `send_message_to_qq` / `send_meme_to_qq` / `send_poke`，再叠加 `time_injector` 每 60 秒往对话里注入一条新的 HumanMessage（模型会当成「又来了一条消息」继续接话），于是一轮跑图能拖好几分钟、发十几条气泡。现在给一轮里的各类发送各设上限，超了直接拒绝并把模型引导回最终回复。

## Added

- 顶层 `send_budget` 配置（`models/config/send_budget.py`）：
  - `enable`（默认 `true`）：开关；
  - `max_messages`（默认 `3`）：一轮最多发几条文字；
  - `max_memes`（默认 `2`）：一轮最多发表情包；
  - `max_pokes`（默认 `1`）：一轮最多戳几次；
  - 任何一项填 `0` 表示该类不限。
- `utils/send_budget.py`：按 `thread_id` 计数的一轮预算，`ON_AGENT_START` 时重置、`ON_AGENT_END` 时清理（`MiaoLiQQChannel` 注册处理器）。
- 三个发送工具接入预算：`send_message_to_qq` 返回「本轮发送次数已用完 把剩下的话放进最终回复」，`send_meme_to_qq` 返回同样意思的 JSON，`send_poke` 返回「本轮戳一戳次数已用完」。

## Why

2026-11-26 18:09 那次 `group-1046279455` 的随机开窗（未读 18 条）跑了 5 分钟还没停：checkpoint 里能看到 18:11 注入了一条 `time-inject` HumanMessage，之后模型又发了两轮「文字 + 表情包」；到重启前已经发了 7 条文字 + 5 个表情包。

## Config

```yaml
send_budget:
  enable: true
  max_messages: 3
  max_memes: 2
  max_pokes: 1
```

`enable: false` 退回 0.16.2 行为（只靠模型自觉）。
