# v0.13.0 - 2026-11-25

> 🎭 **新增 `persona_ops` 子插件**：不改人设、不硬套模板，只在合适的那一轮往 `messages` 末尾塞一条「如果气氛合适，可以…」的建议，让模型自己判断要不要接。正经场合收刺、被亲近时接住、被逗时补刺、对方自嘲时先接情绪 —— 四类信号来自当前这轮的正则粗筛，再过冷却与概率。

## Added

- `plugins/persona_ops/`：`inject_persona` 挂 `ON_AGENT_START`（`NORMAL`），按 `thread_id` 维护轮次、冷却与上一轮的 undo；提示写进 `human_injector` 的注入表，由 `injections_reader` 渲染成 `<persona-hint>` 段。
- `plugins/persona_ops/config.example.yaml`：`enable`（默认 `false`）/ `probability`（默认 0.6）/ `cooldown_turns`（默认 3）/ `kinds`；类别写错直接报错。
- `tests/test_persona_policy.py`：匹配类别、冷却、概率、文本归一、提示措辞、配置默认值。
- `bench/persona_compare.py`：长上下文对比实验。离线模式量化注入频率 / 上下文占比 / 提示落点；`--live` 接 OpenAI 兼容接口跑「默认人格 vs 追加一条提示」两臂，并对比表达指标。

## Notes

- 插件默认关闭；不建 `config.yaml` 时只登记配置、不挂节点，升级不会突然改变说话方式。
- `kinds` 默认只开 `tease` / `self_deprecate`：另外两类实测冗余或与人设冲突，要开自己在 `config.yaml` 里加。
- 实测（codeseed `deepseek-v4.1-flash`，1 万 / 3.9 万字上下文）：默认人格没有明显随上下文漂移，追加提示的偏移也很小；成对盲评 12 对 6:6，`tease` 占优、`affection` 反而输。
- 提示只扫当前这轮的用户消息，不看历史；正则宁可不命中，避免把引用、否定、反讽当成信号。
- 依赖 `human_injector`，因此 `miaoli_bot` 仍需 `>= 0.59.0`（按会话注入表）。
