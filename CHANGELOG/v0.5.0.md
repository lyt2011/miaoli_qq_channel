# v0.5.0 - 2026-11-10

> 🧱 **把整个判定框架删了，通道只负责「寻址」**。三个内置判定器（被@ / 被叫昵称 / 私聊）全是「这一条是不是冲我来的」的单条谓词，而判定器却按批次跑、还带优先级与分数累加 —— 一个能 `any()` 的同步判断被包成了异步流水线。本版把判定搬到**入区同步路径**，把「该不该说话」整段交还给图。
>
> 净删约 330 行，删掉 6 个模块，通道第一次有了「主动唤醒入口」。
>
> 破坏性变更：`reply` 换了签名、`BaseChannel` 多了 `platforms`、消息不再有 `to_text()`、配置段 `judge` 与 `submit.min_submit_score` 删除，所以 minor 升到 0.5。

## Added

- `WakeMessage`（`core/channel/qq_channel_message.py`）：不是 QQ 事件，而是主包侧定时唤醒插件推过来的「主动说一句」。正文自带提示词，主包把它当普通渠道消息一样送进图 —— 不定制路径、不进积压区、不劫持别人的提交。
- `api/wake_ops.push_wake_message(thread_id, content) -> bool`：把唤醒塞进就绪区并立刻 `please_run_graph()`。空正文直接 `raise ValueError`（主包在上游就会把它当无内容丢掉，到这里已经是设计错误）；就绪区满了或会话已在排队时返回 `False`，都是瞬态、下一轮再来。
- `ThreadBacklog.active_threads`：当前有积压的会话数，打日志用。
- `QQChannel.platforms`：`frozenset({"qq"})`，主包 0.44.0 起要求通道声明自己支持哪些平台。
- `is_addressed(event, bot_id, nickname)` 与三个谓词（`is_private` / `is_at_me` / `is_name_mentioned`）：`any()` 串起来的纯函数，规则写死在代码里，状态由外面送进来。

## Changed

- 积压缓冲从「一条全局 deque」换成**每个会话一条队列**（`ThreadBacklog`）：`dict[thread_id, deque[(event, addressed)]]`，`pop_window()` 一次取走整个会话的积压、组内保持「旧 → 新」。
- 溢出策略：`message.buf_size` 满了只丢**最旧的未寻址消息**；全是「冲我来的」时允许超限（丢谁都是漏），并且单窗只把最新 `cap` 条送进图，免得一窗灌爆上下文。
- `backlog_anything()` 在入区时就把 `addressed` 算好：同步、O(1)、零 `await`。之后不再重算。
- 提交时机从「全局定时扫描」换成**每个会话一个观察任务**（debounce）：`backlog_anything()` 收到一条寻址消息就 `watch_thread(thread_id)`，任务先睡 `submit.quiet` 秒，醒来比较积压条数 —— 变了说明还在说话、重新计时；没变就尝试提交。**只有提交成功任务才退出**，就绪区满了就一直等，否则提前放开后那段对话就再没人开窗。
- `ThreadBacklog.count(thread_id)`：给 debounce 用的条数探针。
- **随机开窗**：没人 @、没叫到名字的消息，按 `submit.chance`（默认 10%）**逐条**摇骰子，命中就立刻把该会话的整个积压交出去，**不等补充** —— 本来也没人在跟它说话。摇中之后进 `submit.cooldown`（默认 120 秒）冷却，冷却期内连摇都不摇。
- `ThreadBacklog.roll_dice(thread_id, chance, cooldown)` / `mark_rolled(thread_id)`：骰子判定与冷却记录分开。**摇不中不占冷却**（否则一段对话里只能摇一次，概率会低到几乎不触发），**没开成窗也不占冷却**（让位 / 满了不算数）。
- 随机开窗在就绪区非空时**让位**（`submit_window(require_empty=True)`），避免挤掉被 @ 的那条。
- `QQChannel.drain()` 不再分组打包：就绪区里已经是每会话一条，直接**一次取空、原地 `clear()`**。`drain()` 内部不加 `await` —— 外层 `wait_for()` 一旦取消，已经取出的消息就没了。
- `QQChannel.reply(platform, thread_id, content)`：签名对齐主包 0.44.0。`platform` 不在 `platforms` 里就 `raise ValueError`；正文 `str` 直接用，块列表只认 `text` 块，遇到别的块 `raise NotImplementedError`（显式炸，不静默截断）。
- `manifest.toml` 依赖从 `miaoli_bot >= 0.43.0` 改成 `>= 0.44.0`。

## Note

- **`addressed` 不决定说不说**，只决定「溢出时先丢谁」。窗口照常对所有有积压的会话打开，说不说由图里的 `output_checker` 决定。`False` 的含义是「看不出证据」而不是「确定不是冲我来的」，所以没证据的消息仍然留在上下文里。
- **自己发的消息一律 `addressed=False`**：不这么判就会自激 —— 机器人自己的发言被当成「被叫名字」。
- 两个 60 秒节拍器的问题本轮解决：提交时机改成「静默 8 秒」的 debounce，且通道一提交就主动 `please_run_graph()`。
