# v0.14.1 - 2026-11-25

> 🐛 **跟随窗口自激**：成功群回复后打开的跟随窗口，每次回复都会重新 `open_followup`（配额与时长一起重置）。而跟随窗口里每条普通消息都能单独触发一轮提交，于是「回复 → 续窗 → 消息 → 回复」永远关不掉：只要群聊没安静超过 `followup_minutes`，她就会对每条消息各跑一次图。

## Fixed

- `submit_window` 在提交时记下这一窗里有没有「冲我来的」消息（`ThreadBacklog.has_addressed`），并通过 `QQChannelMessage.addressed` 带到通道。
- `QQChannel.reply` 只在**被寻址**的那一轮回复后 `open_followup`；跟随窗口里的回复不再续窗，配额按普通消息自然消耗，最多连带跟随 `followup_messages` 条就停。

## Notes

- 被 @ / 被叫名字 / 私聊的回复仍会正常开跟随窗口。
- 跟随窗口内每条普通消息仍可单独触发一轮跟随（这是「跟随」的本意）；要更省可以把 `followup_messages` 调小。
