# v0.14.0 - 2026-11-25

> 👆 **新增 `poke_ops` 子插件**：人聊天时不时会戳一下对面，光是打字太规整。这个子插件隔一阵往注入表里塞一条「如果气氛合适，可以戳一戳对方」的建议，模型自己决定要不要调 `send_poke`；同一会话有最短间隔，提示只在当轮存在，回合结束就撤。

## Added

- `plugins/poke_ops/`：`inject_poke` 挂 `ON_AGENT_START`（`NORMAL`），按 `thread_id` 记录上次提示时间，`interval_minutes`（默认 10）内不再注入；`clear_poke` 挂 `ON_AGENT_END` 把提示撤掉。
- `plugins/poke_ops/config.example.yaml`：`enable`（默认 `false`）/ `interval_minutes`（默认 10，1–1440）。
- `tests/test_poke_policy.py`：配置默认值与范围、`is_due` 边界、提示措辞、文本归一。

## Notes

- 插件默认关闭；不建 `config.yaml` 时只登记配置、不挂节点，升级不会突然开始戳人。
- 只给建议、不直接执行：模型看上下文里的 QQ 号，自己决定戳谁、戳不戳；不想戳就照常说话。
- 提示依赖 `human_injector` 的按会话注入表，因此 `miaoli_bot` 仍需 `>= 0.59.0`。
- 上次提示时间存在进程内存里，重启后从零开始计时。
