# v0.11.0 - 2026-11-25

> 💉 **`meme_ops` 的可用表情清单从 `prompts` 迁到注入表**：`inject_memes` 不再每轮重写系统提示词的 `available-memes` 段，改成调用 `human_injector` 的 `inject_human("available-memes", …)`，由它在 `messages` 末尾渲染成一条固定 id 的 `HumanMessage`。表情表一变动不再让整段系统提示词前缀缓存失效，清单也不会一轮叠一条。

## Changed

- `plugins/meme_ops/nodes/inject_memes.py`：产出从 `{"prompts": {"available-memes": …}}` 改成写注入表（同名覆盖，旧 undo 自动失效），返回 `None`。
- `plugins/meme_ops/metadata.toml`：新增依赖 `human_injector`（`[[dependences]]`），描述同步。
- `manifest.toml`：版本 0.10.0 → 0.11.0；`dependencies.miaoli_bot` 从 `>=0.44.0` 提高到 `>=0.58.0`。

## Notes

- **破坏性**：`meme_ops` 现在依赖 `miaoli_bot >= 0.58.0`（`human_injector` 是 0.58.0 才有的子插件）。装到更老的主包上时，子插件拓扑排序会因为缺失依赖**整体报错**（不是只跳过 `meme_ops`），两个仓库要一起升级。
- `inject_doc` 的静态帮助文档（`meme-helper` 段）仍然留在 `prompts`：它是固定说明，放系统提示词里缓存更划算。
- `time_injector` 不在本次迁移范围内：旧的时间消息必须留在历史里，模型靠时间轴判断时间流逝，换成固定 id 替换会把这条信息抹掉。
