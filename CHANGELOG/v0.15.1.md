# v0.15.1 - 2026-11-25

> 🐛 **聊天中默认不再自动跟话**：0.15.0 里 active 状态会在安静 `quiet` 秒且过了发言冷却后自动提交一窗，实测连续聊天时每段自然停顿都会再开一窗，观感仍是「一条消息一次」。本版把「跟一句」收进配置 `social.follow_up`，默认关闭；关掉后普通消息除了摇中 `social.chance`，不再触发跑图。

## Fixed

- `core/social/state.py`：`SocialStore.decide()` 在 active 状态下默认不再返回 `WakeReason.ACTIVE`，只有 `social.follow_up: true` 时才走原来的「静默 + 发言冷却」跟话路径。
- 修掉「聊着聊着，同一轮对话隔两三分钟又跑一次图」：第二窗只会在被叫（@ / 昵称 / 关键词 / 引用 / 提问）或随机概率命中时出现。

## Added

- `social.follow_up`（默认 `false`）：显式开启后才允许聊天中主动跟一句，仍受 `quiet`、`speak_cooldown_seconds`、每分钟/每小时提交上限约束。

## Changed

- 测试 54 个：状态机、调度器、回放用例改为断言「默认不跟话」，另留 `follow_up: true` 的限流用例；`tests/fakes.py` 增加该配置项。
- README、`docs/social-state-machine.md`（§5 状态表 / 转移表、§16.1）、`config.example.yaml` 同步说明默认行为。

## Notes

- `social.follow_up` 关闭期间，active 状态只影响状态展示、冷场回潜水与随机概率的统计口径；普通消息一律只入队。
