# v0.7.0 - 2026-11-14

> 🧱 **把 QQ 相关的东西收回这个仓库**。`easier_send`（群 / 私聊发送）从 `miaoli_bot.utils` 迁入本插件的 `utils/`，`meme_ops` 子插件从 `miaoli_bot/plugins/` 整体迁入 `plugins/`。同版新增可选的语料录制：把每条收到的消息按行写进 JSONL，默认关。

## Added

- `utils/easier_send.py`：`easier_send(mode, chat_id, ob11_message, ncatbot_api=None)`，`mode` 支持 `"group"` / `"private"`，其它值 `raise ValueError`。
  - 与主包原实现逐行相同，唯一差别是不再直接 `SHARE_STORE.recall(NCATBOT_API)`，改走 `miaoli_bot.api.get_ncatbot_api()` —— 子插件不碰共享容器。
  - 迁入后消费方是：`core/channel/qq_channel.py` 的 `reply`、`plugins/qq_platform_tools/tools/send_message.py`、`plugins/meme_ops/tools/send_meme.py`。
- `plugins/meme_ops/`：整个子插件迁入本仓库（`README.md` / `main.py` / `consts/` / `core/` / `data/` / `models/` / `nodes/` / `tools/`）。`tools/send_meme.py` 的 `easier_send` 改从 `miaoli_qq_channel.utils` 取，其余代码与迁入前一致，仍然通过 `miaoli_bot.api` / `miaoli_bot.models` / `miaoli_bot.consts` 挂节点与工具。
- `core/corpus_writer.py`：`CorpusWriter` + `to_record(event)`。`to_record` 把一条消息事件解析成一行 JSON（`time` / `timestamp` / `thread_id` / `type` / `group_id` / `group_name` / `user_id` / `nickname` / `card` / `message_id` / `text`），`text` 是 `render_event()` 的渲染结果。
- `models/config/corpus.py`：`CorpusConfig`（`enable` / `path` / `encoding` / `flush`），`enable` 默认 `false`。

## Changed

- `main.py`：`on_load` 在 `corpus.enable` 为真时打开语料文件、`on_close` 关掉；`backlog_anything` 第一件事就是写语料。放在最前面是有意的 —— 后面任何早退分支都不会漏记。
- `core/channel/qq_channel.py`、`plugins/qq_platform_tools/tools/send_message.py`：`easier_send` 的导入源从 `miaoli_bot.utils` 改为本包。

## Note

- 语料默认写到 `data/corpus.jsonl`（`path` 留空时），目录不存在会自动建。`flush: true` 每条刷盘，崩溃最多丢最后一条。
- 语料记的是**渲染后**的文本，不是原始 ob11 结构 —— 图片只剩 URL、转发只剩条数。
- `plugins/meme_ops/config.yaml` 不入库（`.gitignore` 里 `config.yaml` 匹配所有层级）。真实配置里的 `help_doc.path` 是绝对路径，迁到新目录后必须跟着改；`config.example.yaml` 用 `$workspace/data/meme_helper.md`，照模板复制就不会踩。
- 本版之后 `miaoli_bot` 侧不再有 `easier_send`：`from miaoli_bot.utils import easier_send` 会 `ImportError`，`miaoli_bot.api.easier_send` 不再存在。主包那边发版时会另行记录。
- `plugins/meme_ops/consts/share_store_keys.py` 的键前缀仍是 `miaoli_bot/subplugin/meme_ops.*`：那是共享容器的命名空间标识，跟着目录搬家改键会让旧状态读不到，所以没动。
